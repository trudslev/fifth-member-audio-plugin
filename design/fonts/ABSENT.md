# ABSENT — fifth-member/fonts/

**Absent by decision. Nothing to add here.**

- **Permanent Marker** — the nameplate and all four tape strings. **Not embeddable in a shipping
  binary**, so **the letterforms ship as artwork and the font does not**: they are baked into
  `plate/fifth-member-plate-3x.png` (4020 × 3036, 3× of the current 1340 × 1012 frame). Declared in
  `GUI-SPEC.md` §10. **Absent by licensing, not missing.**

Barlow Condensed SemiBold and Share Tech Mono are both present, so this casting is **not** behind the
§11 type-adoption gate.

**This directory exists so that its shortness is a statement.** An empty or missing `fonts/` reads as
an oversight, and an absent font read as an oversight gets "fixed" by substituting a face — which
moves every measurement taken from the nameplate. Register: `shared/FONTS.md`.
